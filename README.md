# Farmsharp

Maize price forecast and ProfitWise for Ilorin, Kwara State. Built with Streamlit.

## Run it
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `app.py` – the whole app (comments explain each part)
- `data/farmsharp.csv` – Ilorin maize price data (World Bank)
- `requirements.txt` – packages to install
